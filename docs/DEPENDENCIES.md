# Dependencies

- React and React DOM render the application.
- Vite, its React plugin, and TypeScript build and check the application.
- Tailwind CSS and its Vite plugin provide styling support.
- Vitest runs local domain tests.
- The lockfile records exact dependency versions. The package-manager version is pinned in `package.json`.
- Runtime data is bundled locally. No external taxonomy service is needed to browse the sample.
